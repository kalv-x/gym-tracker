# Gym Tracker

A personal weekly gym log that installs on Android as an app (open the site in Chrome, then Install).

- Everything is saved on the phone. Use **Past weeks → Export** to make a backup file, and **Import** to restore one.
- Works offline once installed.
- To update the app, change the files here and push. Phones pick up the new version the next time the app is opened online. If you change anything other than `index.html`, bump `VERSION` in `sw.js`.
